# Intent Statement

## Problem Statement

The purpose of this project is to build an entry for the Resurrection category of the Kiroween 2026 hackathon [Q1].

It resurrects the simple play experience of classic handheld electronic games (Game & Watch-style LCD games) in an AI-era setting [desc]. It keeps the monochrome LCD-style pixel art, simple controls and short play sessions, while replacing the falling objects with modern AI and computing items [desc].

## Target Customer

The game targets both hackathon judges and participants, and general web users [Q2]. For judges it aims for impact at presentation time; for general users it aims to be playable instantly in a browser [Q2].

## Success Metrics

Success means both technical quality (PC and smartphone support, retro UI effects, sound effects) and solid gameplay are in place [Q3]. Concretely, the target state is [Q3]:

- The game is playable on both PC and smartphone [Q3]
- A monochrome LCD-style retro presentation is reproduced [Q3]
- Sound effects are implemented [Q3]
- The game is genuinely fun to play [Q3]

## Initiative Trigger

The trigger is participation in the Kiroween 2026 hackathon (Resurrection category), using it as the occasion to realise an unexpected combination of AI and retro games [Q4]. A further motivation is the wish to revive retro game culture against the backdrop of the AI era [Q4].

## Initial Scope Signal

- **Workflow-selected scope**: `poc` [scope]
- **User-confirmed product boundary**: Additional features such as global rankings, daily challenges and Ghost Replay are excluded from this first version [Q7]
- **Confirmed technical boundary**: The game is built as a web game that runs in the browser [Q8]. Server-side processing is not part of the initial version [Q9].
- **Confirmed project name**: The project name is "AI CATCH" [Q10].
