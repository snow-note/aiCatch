# Team Allocation: AI CATCH (four-stage MVP)

A **Bolt** is one build pass over a piece of the work that ends in something that runs and is checked. A **mob** is the group that builds a Bolt together. The Bolts are listed in `bolt-plan.md`; the units they build are in `aidlc/spaces/default/intents/261113-ai-catch-mvp/inception/units-generation/unit-of-work.md`.

Team Formation did not run for the `mvp` scope, so there is one mob for the whole plan.

| Bolt | Unit | Mob | Human role |
|---|---|---|---|
| B1 | U1 u1-game-rules | aidlc-developer-agent (AI) | The developer approves each stage, the code plan, and the Unit checkpoint |
| B2 | U2 u2-screens-and-art | aidlc-developer-agent (AI) | Same; plays the game to check the look on desktop and phone |
| B3 | U3 u3-sound | aidlc-developer-agent (AI) | Same; listens to the sounds |
| B4 | U4 u4-accessibility | aidlc-developer-agent (AI) | Same; tries a screen reader if available |
| B5 | U5 u5-publishing | aidlc-developer-agent (AI) | Same; does the GitHub and Cloudflare Pages account steps |

There is one team, so no cross-team board is needed. The developer is the only person, decides everything, and self-reviews each pull request (`aidlc/spaces/default/intents/261113-ai-catch-mvp/inception/practices-discovery/team-practices.md`).
